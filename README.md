# 📁 1. Data Cleanser

A project focused on preprocessing a synthetic healthcare dataset.

### Features
- Missing value handling
- Outlier detection and treatment
- Data cleaning workflow
- Final cleaned dataset generation

### Techniques Implemented

#### Missing Value Handling
- Mean Imputation
- Most Frequent Imputation
- Random Sampling + Missing Indicator
- KNN Imputation
- MICE Imputation

#### Outlier Handling
- Z-Score Method
- IQR Method
- Percentile Capping
- Winsorization

### Best Methods Selected
- **Best Imputation:** MICE
- **Best Outlier Handling:** IQR

### Output
- Cleaned healthcare dataset ready for ML
